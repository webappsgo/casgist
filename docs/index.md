# CasGist Documentation

Production-ready, self-hosted GitHub Gist alternative.

## Quick Start

```bash
# Docker
docker run -d -p 64080:80 ghcr.io/casapps/casgist:latest

# Binary
wget https://github.com/casapps/casgist/releases/latest/download/casgist-linux-amd64
chmod +x casgist-linux-amd64
./casgist-linux-amd64
```

## Features

- Zero dependencies single binary
- Full Git integration
- Organizations & teams
- 2FA/WebAuthn
- GDPR compliant
- Import from GitHub/GitLab
